# Team Allocation: expense balance columns

A Bolt is one build pass over a piece of the work, ending in something that runs. A mob is the group that builds a Bolt together. The classic plan has no team formation stage, so every Bolt is planned for the AI developer agent (aidlc-developer-agent), with the person approving each code plan.

| Bolt | Unit | Mob | Human role |
|---|---|---|---|
| 1 | U1 u1-schedule-balance | aidlc-developer-agent | approves the code plan; reviews the unit at its checkpoint |
| 2 | U2 u2-api-balance | aidlc-developer-agent | approves the code plan; reviews the unit at its checkpoint |
| 3 | U3 u3-web-balance | aidlc-developer-agent | approves the code plan; reviews the unit at its checkpoint; checks the sticky column and popup width by eye in a browser |

There is one team, so no program board (a cross-team plan of who builds what when) is needed.
