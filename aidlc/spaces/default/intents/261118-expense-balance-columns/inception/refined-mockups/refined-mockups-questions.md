# Refined Mockups Questions: expense balance columns

The expense table grows from 2 columns (Month, Amount) to 8 columns. These questions settle how it looks on the saved contract's Expense schedule tab and in the Expense schedule preview popup.

## Question 1
How should the wider expense table fit the screen?

A. Keep one line per header and let the table scroll sideways, with the Period column kept in view while scrolling
B. Wrap long headers onto two lines (for example "ST Accrued" over "Liability") so most screens fit all 8 columns without scrolling; scroll sideways only on narrow screens
X. Other (please specify)

[Answer]: A
