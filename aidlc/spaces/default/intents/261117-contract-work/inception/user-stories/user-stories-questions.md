# User Stories Plan and Questions

Plan: write INVEST stories with Given/When/Then acceptance criteria and a MoSCoW priority for each, built from the approved requirements (FR1 to FR7, NFR1 to NFR7).

## Q1. [Product owner] Who uses the system?

The requirements say there is no sign-in in this version, but the stories are written from a user's point of view, so we need to know whose.

A. One persona: a contract manager who enters contracts and reads the schedules
B. Two personas: a contract manager who enters contracts, and a finance reviewer who only reads the schedules
X. Other (please specify)

[Answer]: A

## Q2. [Product owner] How should the stories be broken down?

This sets the size and order of the stories.

A. By workflow: enter a contract, generate the schedules, view saved contracts
B. By feature area: contract details, payment streams, expense methods, schedules, saved contracts list
C. One story per requirement group (FR1 to FR7)
X. Other (please specify)

[Answer]: B
